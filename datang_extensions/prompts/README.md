# TradingAgents-astock Prompt Layer

This directory is reserved for Datang prompt overlays.

Rules:

- Keep upstream prompts unchanged unless a sync task explicitly requires a conflict fix.
- Store Datang prompt variants here with a version, owner, purpose, and evaluation note.
- Do not include API keys, private datasets, or broker/trading credentials.
- Prompts may create research hypotheses, but must not promise alpha or executable orders.
